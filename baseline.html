AFT Outputs

Baseline Maps

AFT Baseline maps provide highly accurate synchronic magnetic reconstructions of the entire solar surface.

AFT Baseline Database

By directly assimilating SDO/HMI magnetograms, the AFT model produces continuous, high-fidelity reconstructions of the solar surface magnetic field, serving as a key benchmark for coronal and space weather modeling.

The full dataset is hosted externally in our data repository.

access AFT Baseline Repository ↗

AFTpy Python Library

Simplify your workflow and analyze baseline maps programmatically with aftpy. This Python library provides robust tools to load, visualize, and calculate properties from AFT data.

Easily installable via pip from PyPI.
